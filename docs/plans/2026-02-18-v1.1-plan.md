# BatchCropper v1.1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add four quality-of-life features to BatchCropper: aspect ratio lock, keyboard shortcuts, per-file crop overrides, and image info display.

**Architecture:** All changes live inside `index.html`. The foundation task renames `cropRect` to `batchCrop` and introduces an `activeCrop` pointer that always references the current edit target (either the batch default or a file-specific override). All four features build on top of this.

**Tech Stack:** Vanilla JS, single HTML file, no build step, no test runner. Verification is done by opening `index.html` in a browser and running manual checks plus `console.assert()` in DevTools.

**Design doc:** `docs/plans/2026-02-18-v1.1-design.md`

---

### Step 1: Add `escapeHtml` helper

The existing `renderFileList` uses `innerHTML` with `f.file.name` directly. A file named
`"><img src=x onerror=alert(1)>.jpg` would execute script. Add a helper near the top of
the script block, after the `const` element declarations:

```js
function escapeHtml(str) {
  return str.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');
}
```

Then update the existing `renderFileList` innerHTML to use `escapeHtml(f.file.name)`:

```js
div.innerHTML = `<div class="status"></div><span class="name">${escapeHtml(f.file.name)}</span>`;
```


**In `mousemove` handler — `dragMode === 'new'` block (~line 867):**

## Task 3: Keyboard Shortcuts

**Files:**
- Modify: `index.html` — script block (add one event listener near the bottom)

---

### Step 1: State the expected behavior

Arrow keys nudge `activeCrop.x` or `activeCrop.y` by 1px (10px with Shift). `R` resets.
Neither fires when a text input or select is focused. Page scroll is suppressed.

---

### Step 2: Add the keyboard handler

At the end of the `<script>` block, just before `</script>`, add:

```js
document.addEventListener('keydown', (e) => {
  if (e.target.tagName === 'INPUT' || e.target.tagName === 'SELECT') return;
  if (!imgNatW) return; // no image loaded

  const step = e.shiftKey ? 10 : 1;

  if (e.key === 'ArrowLeft')       { e.preventDefault(); activeCrop.x -= step; }
  else if (e.key === 'ArrowRight') { e.preventDefault(); activeCrop.x += step; }
  else if (e.key === 'ArrowUp')    { e.preventDefault(); activeCrop.y -= step; }
  else if (e.key === 'ArrowDown')  { e.preventDefault(); activeCrop.y += step; }
  else if (e.key === 'r' || e.key === 'R') {
    Object.assign(activeCrop, { x: 0, y: 0, w: imgNatW, h: imgNatH });
    clampCrop();
    updateInputs();
    updateCropBoxVisual();
    return;
  } else {
    return;
  }

  clampCrop();
  updateInputs();
  updateCropBoxVisual();
});
```

### Step 3: Wire the ratio controls in the script

Near the bottom of the script block (before the keyboard handler), add:

```js
const ratioSelect = document.getElementById('ratio-select');
const customRatioInputs = document.getElementById('custom-ratio-inputs');
const ratioW = document.getElementById('ratio-w');
const ratioH = document.getElementById('ratio-h');

function updateAspectRatio() {
  const val = ratioSelect.value;
  if (val === 'free') {
    aspectRatio = null;
    customRatioInputs.style.display = 'none';
  } else if (val === 'custom') {
    customRatioInputs.style.display = 'flex';
    const w = parseFloat(ratioW.value) || 16;
    const h = parseFloat(ratioH.value) || 9;
    const ratio = w / h;
    aspectRatio = isFinite(ratio) && ratio > 0 ? ratio : null;
  } else {
    customRatioInputs.style.display = 'none';
    aspectRatio = parseFloat(val);
  }
}

ratioSelect.addEventListener('change', updateAspectRatio);
ratioW.addEventListener('input', updateAspectRatio);
ratioH.addEventListener('input', updateAspectRatio);
```
