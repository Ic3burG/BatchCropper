# Design Doc: v1.2 Export Enhancements

## Goals

Implement the v1.2 features from the roadmap to improve export flexibility:

- JPEG/WebP quality control.
- Customizable filename templates with placeholders.
- Option to download the active file individually.

## Proposed Changes

### UI / Sidebar (Export Section)

- **Quality Slider**: Add a range input (0.01 to 1.00) with a percentage display.
  - Only visible when Format is "image/jpeg" or "image/webp".
  - Default value: 0.95.
- **Filename Template**: Add a text input with a default value of `{name}_cropped`.
  - Add a small legend showing available placeholders: `{name}`, `{w}`, `{h}`, `{idx}`.
- **Individual Download**: Add a "▼ Download Active File" button above the "Download All" button.

### Logic

- **Template Resolver**: A function to replace placeholders in the template string:
  - `{name}`: Original filename without extension.
  - `{w}`: Cropped width in pixels.
  - `{h}`: Cropped height in pixels.
  - `{idx}`: 1-based index in the file list.
- **Quality Control**: Pass the slider value as the third argument to `canvas.toBlob(callback, format, quality)`.
- **Single Download Function**:
  - Reuses the cropping/canvas logic from the batch export.
  - Triggers an immediate browser download for the currently active file.

### State

- `exportQuality`: Defaults to 0.95.
- `filenameTemplate`: Defaults to `{name}_cropped`.

## Implementation Notes

- Use `display: none` to show/hide the quality slider based on the format selection.
- Ensure the individual download button is disabled if no images are loaded.
- Maintain the single-file architecture of `index.html`.
