# BatchCropper v1.3 UX Polish Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add undo/redo for crop changes, full touch/tablet support (drag, pinch-to-zoom, swipe navigation), and localStorage persistence for all export settings.

**Architecture:** All changes land in the single `index.html` file. Undo/redo uses a capped snapshot array with a cursor. Touch uses the Pointer Events API (replaces mouse events) with a `Map` for dual-pointer pinch tracking. Settings use a `saveSettings()`/`loadSettings()` pair keyed to `batchcrop_settings` in `localStorage`.

**Tech Stack:** Vanilla JS, single HTML file, no build step. Open directly in browser for testing. Prettier pre-push hook auto-formats on `git push`.

**Step 2: Add `pushHistory()` function**

Add this function immediately after the `clampCrop()` function (~line 1106):

```js
function pushHistory() {
  const last = cropHistory[historyIndex];
  if (
    last &&
    last.x === activeCrop.x &&
    last.y === activeCrop.y &&
    last.w === activeCrop.w &&
    last.h === activeCrop.h
  )
    return;
  cropHistory = cropHistory.slice(0, historyIndex + 1);
  cropHistory.push({ ...activeCrop });
  if (cropHistory.length > HISTORY_LIMIT) cropHistory.shift();
  else historyIndex++;
}
```

**Step 2: Track pointers in `pointerdown`**

At the very start of the `pointerdown` handler body (after `e.currentTarget.setPointerCapture(e.pointerId)`), add:

This must go **before** the existing drag-mode detection logic so a second touch cancels the drag and enters pinch mode.

**Step 3: Handle pinch in `pointermove`**

At the very start of the `pointermove` handler body, before `if (!isDragging) return;`, add:

```js
if (activePointers.has(e.pointerId)) {
  activePointers.set(e.pointerId, { x: e.clientX, y: e.clientY });
```

**Step 2: Add `touchstart` / `touchend` listeners on `#file-list`**

Add these two listeners after `clearFilesBtn.addEventListener('click', clearFiles);` near the top of the event-binding section:

```js
fileList.addEventListener(
  'touchstart',
  (e) => {
    swipeStartX = e.touches[0].clientX;
    swipeStartY = e.touches[0].clientY;
  },
  { passive: true }
);

fileList.addEventListener(
  'touchend',
  (e) => {
    if (!files.length) return;
    const dx = e.changedTouches[0].clientX - swipeStartX;
    const dy = e.changedTouches[0].clientY - swipeStartY;
    if (Math.abs(dx) <= 40 || Math.abs(dy) >= 60) return;
    if (dx < 0 && activeIndex < files.length - 1) {
      activeIndex++;
    } else if (dx > 0 && activeIndex > 0) {
      activeIndex--;
    } else {
      return;
    }
    showPreview(activeIndex);
    renderFileList();
  },
  { passive: true }
);
```

**Note on `{ passive: true }`:** Since these listeners never call `preventDefault()`, marking them passive allows the browser to start scrolling immediately without waiting for JS — important for smooth vertical scroll of the file list.

```js
const SETTINGS_KEY = 'batchcrop_settings';

function saveSettings() {
  try {
    localStorage.setItem(
      SETTINGS_KEY,
      JSON.stringify({
        format: document.getElementById('export-format').value,
        quality: exportQuality,
        filenameTemplate,
        ratioSelect: ratioSelect.value,
        ratioW: parseFloat(ratioW.value) || 16,
        ratioH: parseFloat(ratioH.value) || 9,
        zoom,
      })
    );
  } catch (_) {}
}
```

**Step 2: Add `loadSettings()` function**

Add immediately after `saveSettings()`:

```js
function loadSettings() {
  try {
    const raw = localStorage.getItem(SETTINGS_KEY);
    if (!raw) return;
    const s = JSON.parse(raw);
    const formatEl = document.getElementById('export-format');
    if (s.format) {
      formatEl.value = s.format;
      qualityContainer.style.display =
        s.format === 'image/jpeg' || s.format === 'image/webp' ? 'block' : 'none';
    }
    if (s.quality != null) {
      exportQuality = s.quality;
      exportQualityInput.value = s.quality;
      qualityVal.textContent = Math.round(s.quality * 100);
    }
    if (s.filenameTemplate != null) {
      filenameTemplate = s.filenameTemplate;
      filenameTemplateInput.value = s.filenameTemplate;
    }
    if (s.ratioSelect) ratioSelect.value = s.ratioSelect;
    if (s.ratioW) ratioW.value = s.ratioW;
    if (s.ratioH) ratioH.value = s.ratioH;
    if (s.ratioSelect) updateAspectRatio();
    if (s.zoom != null) zoom = Math.min(8, Math.max(0.05, s.zoom));
  } catch (_) {}
}
```
