# v1.4 Crop Intelligence Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add three crop intelligence features: mirror/flip on export, crop-by-percentage inputs, and smart face-crop suggestions via the ShapeDetection API.

**Architecture:** All changes are confined to `index.html`. The file has three zones — CSS styles (lines ~8–580), HTML markup (lines ~580–827), and a `<script>` block (lines ~827–1718). Each feature adds state variables near the top of the script, wires UI in the markup, and adds logic in the script. The underlying `activeCrop` object always stores pixel values — percentage mode is purely a display/input conversion layer.

**Tech Stack:** Vanilla JS, HTML Canvas API (for flip transforms), browser `ShapeDetection` API (FaceDetector — progressive enhancement only), no new dependencies.

Replace the existing `updateInputs()` function (lines ~1181–1186):

```js
function updateInputs() {
  if (cropMode === 'pct' && imgNatW && imgNatH) {
    inX.value = ((activeCrop.x / imgNatW) * 100).toFixed(1);
    inY.value = ((activeCrop.y / imgNatH) * 100).toFixed(1);
    inW.value = ((activeCrop.w / imgNatW) * 100).toFixed(1);
    inH.value = ((activeCrop.h / imgNatH) * 100).toFixed(1);
  } else {
    inX.value = Math.round(activeCrop.x);
    inY.value = Math.round(activeCrop.y);
    inW.value = Math.round(activeCrop.w);
    inH.value = Math.round(activeCrop.h);
  }
}
```

**Step 5: Update `inputsToCrop()` to convert from percentage**

Replace the existing `inputsToCrop()` (lines ~1147–1154):

```js
function inputsToCrop() {
  if (cropMode === 'pct' && imgNatW && imgNatH) {
    activeCrop.x = (parseFloat(inX.value) || 0) / 100 * imgNatW;
    activeCrop.y = (parseFloat(inY.value) || 0) / 100 * imgNatH;
```

### Task 3: Smart Crop Suggestions (ShapeDetection FaceDetector)

Adds a "Detect Faces" button that uses the browser's `FaceDetector` API to suggest a crop region encompassing detected faces. The button is only rendered when `'FaceDetector' in window`. This feature works in Chrome on Android and some Chrome desktop builds on Linux/Windows — **not on macOS Chrome** — so it must be a strict progressive enhancement.

**Files:**

**Step 3: Implement the detection logic**

Add the event listener after the `clear-override` listener (around line 1366):

```js
detectFacesBtn.addEventListener('click', async () => {
  if (!imgNatW || !files[activeIndex]) return;

  detectFacesBtn.disabled = true;
  detectFacesStatus.style.display = 'block';
  detectFacesStatus.textContent = 'Detecting…';

  try {
    const detector = new FaceDetector({ fastMode: false });
    const faces = await detector.detect(previewImg);

    if (!faces.length) {
      detectFacesStatus.textContent = 'No faces detected.';
      detectFacesBtn.disabled = false;
      return;
    }

    // Compute bounding box of all detected faces
    let minX = Infinity, minY = Infinity, maxX = -Infinity, maxY = -Infinity;
    for (const face of faces) {
      const b = face.boundingBox;
      // FaceDetector returns coords in the element's display space, not natural pixels
      // previewImg is displayed at `zoom` scale, so convert back to natural pixels
      minX = Math.min(minX, b.left / zoom);
      minY = Math.min(minY, b.top / zoom);
      maxX = Math.max(maxX, (b.left + b.width) / zoom);
      maxY = Math.max(maxY, (b.top + b.height) / zoom);
    }

    // Add 10% padding around the detected region
    const padX = (maxX - minX) * 0.1;
    const padY = (maxY - minY) * 0.1;
    activeCrop.x = Math.max(0, minX - padX);
    activeCrop.y = Math.max(0, minY - padY);
    activeCrop.w = Math.min(imgNatW - activeCrop.x, (maxX - minX) + padX * 2);
    activeCrop.h = Math.min(imgNatH - activeCrop.y, (maxY - minY) + padY * 2);

    clampCrop();
    updateInputs();
    updateCropBoxVisual();
    pushHistory();

    detectFacesStatus.textContent = `${faces.length} face${faces.length > 1 ? 's' : ''} detected.`;
  } catch (err) {
    detectFacesStatus.textContent = 'Detection failed: ' + err.message;
  }

  detectFacesBtn.disabled = false;
});
```
