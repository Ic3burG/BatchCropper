# v1.5.1 Collapsible Sidebar Sections Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make the Crop, Presets, and Export sidebar sections collapsible via a shared helper, with collapse state persisted in localStorage.

**Architecture:** A single `initCollapsible(toggleBtnId, bodyId, settingsKey)` helper wires a toggle button (`▾`/`▸`) to show/hide a body div and saves state to the existing `batchcrop_settings` localStorage key. Crop and Export get new toggle buttons and body wrapper divs in HTML. Presets already has the right HTML — its ad-hoc toggle code is replaced by the shared helper. The Files section (a compact toolbar, not a scrollable content section) is left unchanged.

**Tech Stack:** Vanilla JS, localStorage. No new dependencies.

### Step 2: Add `initCollapsible` helper function

Add this as a named function declaration (hoisted) anywhere in the script near the other utility functions (e.g., near `updateClearDoneVisibility`):

```js
function initCollapsible(toggleBtnId, bodyId, settingsKey) {
  const btn = document.getElementById(toggleBtnId);
  const body = document.getElementById(bodyId);
  function apply(collapsed) {
    body.style.display = collapsed ? 'none' : '';
    btn.textContent = collapsed ? '\u25b8' : '\u25be';
  }
  btn.addEventListener('click', () => {
    const collapsed = body.style.display !== 'none';
    apply(collapsed);
    sectionCollapsed[settingsKey] = collapsed;
    saveSettings();
  });
  apply(sectionCollapsed[settingsKey]);
}
```
