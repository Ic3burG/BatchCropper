# v1.6 Export Enhancements — Design

## Goal

Three export enhancements: AVIF format support, watermark/overlay stamp (text + logo), and copy to clipboard.

---

## Feature 1: AVIF Format Support

Add `image/avif` as a fourth export format. The Canvas `toBlob('image/avif', quality)` API is natively supported in Chrome and Firefox — no new dependency needed.

**Changes:**

- Add `<option value="image/avif">AVIF</option>` to the format select
- Show quality slider for AVIF (same condition as JPEG/WebP)
- Extend `ext` derivation in both export paths to produce `avif` extension
- Update `loadSettings` to handle the stored AVIF format value

No new state required.

---

## Feature 2: Watermark / Overlay Stamp

A collapsible watermark subsection in the Export sidebar (between filename template and resize block).

### UI

- Enable checkbox ("Watermark")
- Text input (placeholder "© Your Name")
- Logo file input ("Choose Logo…" button + "×" clear button)
- Corner picker: 2×2 grid of 4 small buttons (TL · TR / BL · BR), active corner highlighted in accent color
- Opacity slider (0–100%, default 80%)
- Font size input (px, default 16, only visible when text is non-empty)

### State

| Variable            | Type                   | Default | Persisted                       |
| ------------------- | ---------------------- | ------- | ------------------------------- |
| `watermarkEnabled`  | boolean                | false   | yes                             |
| `watermarkText`     | string                 | ''      | yes                             |
| `watermarkCorner`   | 'tl'\|'tr'\|'bl'\|'br' | 'br'    | yes                             |
| `watermarkOpacity`  | number 0–1             | 0.8     | yes                             |
| `watermarkFontSize` | number                 | 16      | yes                             |
| `watermarkLogoImg`  | Image\|null            | null    | **no** — re-select each session |

The logo is not persisted (binary data would bloat localStorage). All other watermark state is stored in `batchcrop_settings`.

### Export Logic

A shared `applyWatermark(canvas, ctx)` helper called after the image draw (and after flip/resize). Steps:

1. Set `ctx.globalAlpha = watermarkOpacity`
2. If logo loaded: scale to fit within 25% of the shorter canvas edge, position at chosen corner with 8px margin
3. If text non-empty: draw with `ctx.fillText`, 8px margin from corner, dark text shadow for legibility on any background
4. Reset `ctx.globalAlpha = 1`

Logo and text can coexist at the same corner (logo drawn first, text below/beside it).

---

## Feature 3: Copy to Clipboard

A "⧉ Copy to Clipboard" button in the Export section, below "Download Active File".

### Behavior

- Uses the same canvas draw path as `downloadActiveFile`
- Writes result as PNG via `navigator.clipboard.write([new ClipboardItem({ 'image/png': blob })])`
- Always PNG regardless of selected format (Clipboard API cross-browser constraint)
- On success: button briefly shows "Copied!" then reverts
- Does **not** mark file as done (non-destructive action)

### Progressive Enhancement

If `navigator.clipboard?.write` is unavailable, the button is hidden (same pattern as face detection). Hidden on browsers that don't support the Clipboard API.
