# v1.7 Visual Aids — Design

## Goal

Two visual aid features: independent grid overlay toggles (rule-of-thirds + golden ratio) and a side-by-side crop comparison view.

---

## Feature 1: Golden Ratio Grid Overlay

### Current State

The rule-of-thirds grid is always-on — hard-coded as a CSS `::before` pseudo-element on `#crop-box` using `linear-gradient`. No JS state controls it.

### Approach

Convert to a class-controlled system:

- `#crop-box.grid-thirds` shows rule-of-thirds via `::before`
- `#crop-box.grid-golden` shows golden ratio via `::after`

Golden ratio lines are at **38.2% / 61.8%** (φ = 1.618…, 1/φ ≈ 0.618).

### UI

Two small toggle buttons in the Crop section body (near Reset/Save buttons):

- `⊞ ⅓` — toggles rule-of-thirds
- `⊞ φ` — toggles golden ratio

Active state highlighted in accent color. Both can be on simultaneously.

### State

| Variable         | Type    | Default | Persisted |
| ---------------- | ------- | ------- | --------- |
| `showThirdsGrid` | boolean | `true`  | yes       |
| `showGoldenGrid` | boolean | `false` | yes       |

Default of `true` for thirds preserves current always-on behavior.

### CSS Changes

Remove the unconditional `::before` background and replace with class-gated rules:

```css
#crop-box.grid-thirds::before {
  background:
    linear-gradient(to right, rgba(255, 255, 255, 0.15) 1px, transparent 1px) 33.33% 0 / 33.33% 100%,
    linear-gradient(to bottom, rgba(255, 255, 255, 0.15) 1px, transparent 1px) 0 33.33% / 100%
      33.33%;
}

#crop-box.grid-golden::after {
  content: '';
  position: absolute;
  inset: 0;
  background:
    linear-gradient(to right, rgba(255, 255, 255, 0.15) 1px, transparent 1px) 38.2% 0 / 38.2% 100%,
    linear-gradient(to bottom, rgba(255, 255, 255, 0.15) 1px, transparent 1px) 0 38.2% / 100% 38.2%;
}
```

## Feature 2: Crop Comparison View

### Approach

A **"◫ Compare"** toggle button in the canvas toolbar (next to zoom controls). When active:

- A `<canvas id="compare-canvas">` is shown, absolutely positioned over the canvas area, same dimensions as `#canvas-area`
- The crop editor (image + overlay + handles) gets `pointer-events: none; opacity: 0` — stays in DOM but invisible
- Toggling off hides the compare canvas and restores the crop editor

### Rendering

The comparison canvas is split into two equal halves by a 1px vertical divider line:

- **Left half** — full original image scaled to fit (letterboxed), with the crop rectangle drawn as an accent-colored outline
- **Right half** — the cropped region only, scaled to fill the available space (letterboxed)
- If no crop is drawn, right half shows centered text: `"No crop selected"`

The canvas re-renders on every crop change while compare mode is active (hooked into the existing crop update path).

### State

| Variable      | Type    | Default | Persisted |
| ------------- | ------- | ------- | --------- |
| `compareMode` | boolean | `false` | **no**    |

Not persisted — compare mode is a momentary inspection tool, not a sticky preference.

### DOM

```html
<canvas
  id="compare-canvas"
  style="display: none; position: absolute; inset: 0; pointer-events: none;"
></canvas>
```

Added inside `#canvas-area` alongside the existing image and overlay elements.

The compare button goes in the canvas toolbar, after the existing zoom buttons.
