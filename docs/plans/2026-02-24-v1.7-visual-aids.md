# v1.7 Visual Aids Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add two visual aid features: independent rule-of-thirds / golden-ratio grid overlay toggles, and a side-by-side crop comparison view.

**Architecture:** Both features are confined to `index.html`. Grid overlays are class-controlled CSS pseudo-elements on `#crop-box`. The comparison view uses a `<canvas id="compare-canvas">` that overlays the crop editor when active, re-rendering on every crop change.

**Tech Stack:** Vanilla JS, CSS pseudo-elements, HTML Canvas 2D API. No new dependencies.

**Note:** `pointer-events: none` is added to prevent pseudo-elements from interfering with drag handles. The `::after` background is only set when the `.grid-golden` class is present — when absent it has no background (transparent).

### Step 3: Add `renderCompare` helper function

Add near `updateCropBoxVisual`:

```js
function renderCompare() {
  const crop = activeCrop;
  const cw = compareCanvas.parentElement.offsetWidth;
  const ch = compareCanvas.parentElement.offsetHeight;
  compareCanvas.width = cw;
  compareCanvas.height = ch;
  const ctx = compareCanvas.getContext('2d');
  ctx.clearRect(0, 0, cw, ch);

  const half = Math.floor(cw / 2);
  const dividerX = half;

  // — Left half: full original image scaled to fit —
  const imgW = previewImg.naturalWidth;
  const imgH = previewImg.naturalHeight;
  const scaleLeft = Math.min(half / imgW, ch / imgH);
  const lw = imgW * scaleLeft;
  const lh = imgH * scaleLeft;
  const lx = (half - lw) / 2;
  const ly = (ch - lh) / 2;
  ctx.drawImage(previewImg, lx, ly, lw, lh);

  // Draw crop rectangle on left half
  if (crop.w && crop.h) {
    ctx.strokeStyle = 'var(--accent, #7eb8f7)';
    ctx.lineWidth = 1.5;
    ctx.strokeRect(
      lx + crop.x * scaleLeft,
      ly + crop.y * scaleLeft,
      crop.w * scaleLeft,
      crop.h * scaleLeft
    );
  }

  // — Divider —
  ctx.fillStyle = 'rgba(255,255,255,0.2)';
  ctx.fillRect(dividerX, 0, 1, ch);

  // — Right half: cropped region —
  ctx.save();
  ctx.rect(half + 1, 0, cw - half - 1, ch);
  ctx.clip();

  if (crop.w && crop.h) {
    const scaleRight = Math.min((cw - half - 1) / crop.w, ch / crop.h);
    const rw = crop.w * scaleRight;
    const rh = crop.h * scaleRight;
    const rx = half + 1 + (cw - half - 1 - rw) / 2;
    const ry = (ch - rh) / 2;
    ctx.drawImage(previewImg, crop.x, crop.y, crop.w, crop.h, rx, ry, rw, rh);
  } else {
    ctx.fillStyle = 'rgba(255,255,255,0.3)';
    ctx.font = '13px sans-serif';
    ctx.textAlign = 'center';
    ctx.textBaseline = 'middle';
    ctx.fillText('No crop selected', half + (cw - half) / 2, ch / 2);
  }

  ctx.restore();
}
```

**Notes:**

- Uses `previewImg` (the `<img>` element already loaded in the DOM) as the image source — no need to reload from `File` object
- `var(--accent, #7eb8f7)` falls back to a blue if the CSS variable isn't available in canvas context; since canvas `strokeStyle` doesn't resolve CSS variables, use the literal fallback value `'#7eb8f7'` directly

**Fix for CSS variable in canvas:** Canvas `strokeStyle` does not resolve CSS variables. Replace `'var(--accent, #7eb8f7)'` with `'#7eb8f7'` directly in `renderCompare`.
