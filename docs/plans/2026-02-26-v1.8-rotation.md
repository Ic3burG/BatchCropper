# v1.8 Rotation Handle Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a rotation handle to the crop box so users can rotate the crop selection before export, producing a clean rectangular output (image rotates to match the box).

**Architecture:** CSS `transform: rotate()` on `#crop-box` for live preview; a drag handle `div` positioned above the box for tactile control; sidebar numeric input + slider for precision. At export, `ctx.rotate()` on a temp canvas in a shared `drawCroppedImage()` helper called by all three export paths.

**Tech Stack:** Vanilla JS/HTML/CSS, Canvas 2D API — no new dependencies.

**Step 2: Add pointer listeners on `#rotation-handle` after previewContainer pointerup (~line 2120)**

```js
const rotHandleEl = document.getElementById('rotation-handle');

rotHandleEl.addEventListener('pointerdown', (e) => {
  e.stopPropagation();
  rotHandleEl.setPointerCapture(e.pointerId);
  rotDragActive = true;
  const rect = previewImg.getBoundingClientRect();
  const cx = rect.left + activeCrop.x * zoom + (activeCrop.w * zoom) / 2;
  const cy = rect.top + activeCrop.y * zoom + (activeCrop.h * zoom) / 2;
  rotCenter = { x: cx, y: cy };
  rotDragStartAngle = Math.atan2(e.clientY - cy, e.clientX - cx) * (180 / Math.PI);
  rotDragStartRotation = cropRotation;
});

rotHandleEl.addEventListener('pointermove', (e) => {
  if (!rotDragActive) return;
  const angle = Math.atan2(e.clientY - rotCenter.y, e.clientX - rotCenter.x) * (180 / Math.PI);
  let newRot = rotDragStartRotation + (angle - rotDragStartAngle);
  newRot = Math.max(-180, Math.min(180, newRot));
  if (Math.abs(newRot) < 2) newRot = 0; // snap to level
  cropRotation = newRot;
  syncRotationUI();
  updateCropBoxVisual();
});

rotHandleEl.addEventListener('pointerup', () => {
  if (!rotDragActive) return;
  rotDragActive = false;
  pushHistory();
});
```

**Step 1: Add `drawCroppedImage(ctx, img, crop)` helper after `applyResizeToCanvas`**

```js
function drawCroppedImage(ctx, img, crop) {
  const cw = Math.round(crop.w);
  const ch = Math.round(crop.h);
  const rotation = crop.rotation ?? 0;
  if (rotation !== 0) {
    const rad = -(rotation * Math.PI) / 180;
    if (flipH || flipV) {
      ctx.translate(flipH ? cw : 0, flipV ? ch : 0);
      ctx.scale(flipH ? -1 : 1, flipV ? -1 : 1);
    }
    ctx.translate(cw / 2, ch / 2);
    ctx.rotate(rad);
    ctx.drawImage(img, -(crop.x + cw / 2), -(crop.y + ch / 2), img.naturalWidth, img.naturalHeight);
  } else {
    if (flipH || flipV) {
      ctx.translate(flipH ? cw : 0, flipV ? ch : 0);
      ctx.scale(flipH ? -1 : 1, flipV ? -1 : 1);
    }
    ctx.drawImage(img, Math.round(crop.x), Math.round(crop.y), cw, ch, 0, 0, cw, ch);
  }
}
```
